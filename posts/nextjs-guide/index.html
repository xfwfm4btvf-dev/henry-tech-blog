Next.js全栈开发实战：从零到部署

2026-05-09

Next.js
React
全栈

Next.js 是目前最流行的 React 框架，它让全栈开发变得简单高效。

为什么选 Next.js？

  1. 服务端渲染（SSR）：首屏加载快，SEO 好
  2. API 路由：前后端一体，不用单独写后端
  3. 文件系统路由：目录结构就是路由结构
  4. TypeScript 原生支持：类型安全，减少 bug
  5. 零配置部署：Vercel 一键上线

快速开始

npx create-next-app@latest my-app --typescript
cd my-app
npm run dev

App Router（推荐）

// app/page.tsx - 首页
export default function Home() {
  return <h1>欢迎来到我的网站</h1>
}

// app/blog/[slug]/page.tsx - 动态路由
export default function BlogPost({ params }: { params: { slug: string } }) {
  return <h1>文章: {params.slug}</h1>
}

API 路由

// app/api/hello/route.ts
export async function GET() {
  return Response.json({ message: 'Hello World' })
}

部署

最简单的方式是用 Vercel：

npm i -g vercel
vercel

三步搞定，自动给你一个线上地址。

总结

Next.js 让前端开发者也能轻松做全栈。学会它，你就能独立开发完整的 Web 应用。
